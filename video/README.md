# Commit. ad: video folder

Everything for the 2:00 Commit. ad. Start with [`../VIDEO-SCRIPT.md`](../VIDEO-SCRIPT.md), which compares the two story options.

## What is where

| Path | What it is |
|---|---|
| `screenplays/` | **The screenplays**: what happens, scene by scene, with dialogue and the real screenshots shown where they appear. `option-a-where-you-started.md` (time travel), `option-b-starting-monday.md` (realistic). |
| `option-a-time-travel.md`, `option-b-realistic.md` | Shot tables and joke banks for each option. |
| `inserts/option-a/`, `inserts/option-b/` | **Insert packs for the live shoot**: every phone screen the film uses, in order, named by shot (`shot09a_...png`), with a README of timecodes. |
| `screens/dark/` | The 19 source screenshots of the app (dark theme, 780 x 1688). |
| `films/` | Rendered mp4s: the two animatics and a 1-minute screen recording of the app. |
| `clips/` | `flow.webm`, the raw screen recording (regenerated by `npm run record`, not committed; the mp4 is in `films/`). |
| `animatic/` | The animatic engine (`index.html`) and the shot data (`scenes.mjs`). Edit `scenes.mjs` to change timing or dialogue. |
| `tools/` | The scripts that make all of the above from the real app. |
| `archive/` | The first draft of the script. |

## Regenerating

You need Node 18+ and, for the films, `ffmpeg` and `python3` on your PATH (`brew install ffmpeg`).

```
cd video
npm run setup      # once: installs Playwright and its Chromium
npm run screens    # re-shoot the 19 screens from the app
npm run inserts    # rebuild the insert packs
npm run record     # re-record the app flow
npm run films      # re-render both animatic mp4s
```

The tools start their own small web server for the app, so nothing else needs to be running. If `ffmpeg` is not on your PATH, set `FFMPEG=/path/to/ffmpeg`.

The screens are deterministic: the mock camera and AI verification read `Math.random`, and the tools pin it so a run always gives the gym photo and a 93% pass. `MOOD="Full of energy" npm run screens` answers the chat differently.

## Notes

- The animatic score is a synthesized placeholder (`tools/make-score.py`, standard library only). Replace it with an original or licensed R&B cue for the real film.
- The animatics are 30 fps. Final phone inserts should be screen-recorded on a real phone at 60 fps for fully fluid motion; the motion spec is in `../VIDEO-SCRIPT.md`.
- The proof photo is `img/proof/gym.jpg` (a dumbbell rack, no person), so nothing contradicts Alex being a man.
- `node_modules/` is not committed; `npm run setup` creates it.
